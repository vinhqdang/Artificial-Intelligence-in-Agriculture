# Artificial-Intelligence-in-Agriculture
https://www.keaipublishing.com/en/journals/artificial-intelligence-in-agriculture/

## Projects

- [`agrivoltaics/`](agrivoltaics/): **SALS**, stress-aware light sharing. A differentiable-simulation learning algorithm that designs and controls climate-resilient agrivoltaic systems across the world's staple croplands, for food–energy security under global warming. Includes code, data pipeline, results and the manuscript prepared for *Artificial Intelligence in Agriculture* (`agrivoltaics/manuscript/main.pdf`).
